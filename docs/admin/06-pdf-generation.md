# 06 — PDF Generation (client-side jsPDF)

**Why client-side:** `jspdf@4.2.1` is already installed in AmazeCC-Dashboard but unused.
Generating in the browser avoids new server deps, works offline, and matches the
"download" intent. If `jspdf-autotable` is not installed we draw tables manually
(`doc.rect`, `doc.line`, `doc.text`) — no new dependency.

Shared helpers in `src/components/custom/admin/gorobo/gorobo-pdf.ts`:

- A4 portrait, `jsPDF({ unit: 'pt', format: 'a4' })`.
- Page header: dark bar with "AmazeCC" + document title, orange accent (brand color),
  date/time generated.
- `drawTable(doc, y, columns, rows)` — manual table renderer with header fill, row
  striping, `₹` amounts right-aligned, page-break handling.
- Footer on every page: "Generated by AmazeCC Admin · gorobo" + page number.

## BOM PDF (bill processor → order detail)

Filename: `gorobo-bom-<orderId-prefix>.pdf`

Content:
- Header: **GoRoBo — Bill of Materials / Final Quote**, customer name, phone,
  order ID, created date, status.
- Table (line items): `# | Item | Qty | Unit ₹ | Margin ₹ | Amount ₹` (margin shown for
  inventory lines, `—` for custom lines).
- Summary block (right-aligned): Subtotal, Discount (pct + amount), Taxable,
  GST (pct + amount), Shipment, **Grand Total** (bold, larger).
- Notes paragraph if present.
- Footer: "Prices include GST as per quote. Generated from the bill processor."

## Wallet history PDF (Amaze Wallet)

Filename: `gorobo-wallet-history-<date>.pdf`

Content:
- Header: **Amaze Wallet — Transaction History** + export date.
- Summary strip: Profit total, GST collected, Vendor cost paid, Customer receipts.
- Table (per completed order): `Date | Customer | Phone | Profit ₹ | GST ₹ | Cost ₹ |
  Customer paid? | Vendor paid?`
- Totals row.
- Footer: "Wallet entries are bookkeeping records; settlement is manual."
